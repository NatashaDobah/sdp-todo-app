# Third-Party Libraries

| Library | Version | Reason for Choice |
|---------|---------|-------------------|
| **better-sqlite3** | 9.x | Lightweight SQLite driver with synchronous API. Perfect for local-first apps. No external dependencies. |
| **@types/better-sqlite3** | 7.x | TypeScript type definitions for type safety. |
| **Tailwind CSS** | 4.x | Utility-first CSS framework for rapid UI development. Minimal custom CSS needed. |
| **Next.js** | 14.x | React framework with built-in routing and server components. |
| **Vitest** | 2.x | Fast test runner with built-in mocking and watch mode. |
